# 📋 Requerimientos del Sistema para Nexus OS

Nexus OS está diseñado para ser flexible y escalable, adaptándose tanto a equipos antiguos como a estaciones de trabajo de alto rendimiento.

## 🟢 Requerimientos Mínimos (Modo LOW_END)

*   **Procesador:** CPU de 64 bits de doble núcleo (p.ej., Intel Celeron o superior).
*   **Memoria RAM:** 4GB de RAM (Nexus OS se optimizará automáticamente para este hardware).
*   **Almacenamiento:** 40GB de espacio libre en disco (SSD recomendado).
*   **Gráficos:** Soporte para resolución de 1024x768 píxeles.

## 🔵 Requerimientos Recomendados (Modo HIGH_END)

*   **Procesador:** CPU de 64 bits de 4 núcleos o más (p.ej., Intel Core i5/i7 o AMD Ryzen 5/7).
*   **Memoria RAM:** 16GB de RAM o más (para virtualización de Windows fluida).
*   **Almacenamiento:** 100GB o más de espacio en disco SSD NVMe (para AutoCAD/Adobe).
*   **Gráficos:** Tarjeta gráfica dedicada (NVIDIA o AMD) con soporte Vulkan (para DXVK).
*   **Virtualización:** Soporte para Intel VT-x o AMD-V habilitado en la BIOS.

## 🌐 Conectividad

*   Adaptador de red Ethernet o Wi-Fi.
*   Conexión a internet para descarga de actualizaciones, modelos de IA y software de terceros.

---
Para una experiencia 100% compatible con software profesional de Windows, se recomienda encarecidamente contar con al menos 16GB de RAM.
